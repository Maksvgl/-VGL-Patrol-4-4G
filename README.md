# VGL Патруль 4 — текущая рабочая прошивка

**Текущий подтверждённый комплект: VGL Patrol 1.6, опрос 1400 мс, RF startup delay 5 мс.**
Статус текущей рабочей версии подтверждён владельцем 29 октября 2026 года.

Для полной прошивки через SWD используйте готовый комплект
[`firmware/releases/v1.6-1400ms-rf5ms/`](firmware/releases/v1.6-1400ms-rf5ms/).
Основной файл — `VGL_Patrol_1.6_1400ms_RF5ms_FULL_S132_BOOTLOADER.hex`:
он уже включает **MBR + SoftDevice S132 6.1.0 + приложение 1.6 + загрузчик обновления BIN**.

В этой папке также сохранены исходный батник, отдельные BIN приложения и HEX
загрузчика, лицензионное соглашение SoftDevice и контрольные суммы SHA-256.
Точные имена и хеши закреплены в [`CURRENT_FIRMWARE.json`](CURRENT_FIRMWARE.json).

## Исходники и готовая рабочая сборка

Существующие `main.c`, проекты IAR/SES/Keil и `TEST_PLAN_PPK2.txt` в корне
сохранены как исторические исходники. Их соответствие готовой рабочей сборке
1.6 **не подтверждено**. В историческом `main.c` остаются интервал 400 мс
и RF startup delay 10 мс; не используйте его как эталон параметров текущего BIN/HEX.

При подготовке изменений и стендовой прошивки отправной точкой должен быть
подтверждённый комплект 1.6; исходники его сборки необходимо отдельно сопоставить
с этими бинарными файлами. Файл `FLASH.txt` в корне описывает команды SPI-памяти,
а не процедуру прошивки прибора.
